# Romantic Floral Wedding Invitation Website

A responsive, single-page wedding invitation inspired by the supplied floral invitation mockup. Includes an animated envelope/wax seal, invitation card, live countdown, event schedule, venue section with map link, RSVP form, confirmation screen, photo journey, and replay action.

## Run it
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. Internet access is needed to load Google Fonts and the remote venue/journey photos. The page layout and CSS decorations work without them.

## Personalize
Edit names, date, times, venue, event details and map query in `index.html`. Change the target date in `script.js` too so the countdown matches. Change colors and layout in `style.css`.

## RSVP note
The RSVP form currently shows a confirmation on the page. It does not store or email responses; connect it to a backend or form service for real guest submissions.
